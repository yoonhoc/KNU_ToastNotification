# KNU Toast Notification (경북대학교 컴퓨터학부 공지사항 알리미)

경북대학교 컴퓨터학부 홈페이지의 새로운 공지사항을 확인하여 Windows 바탕화면 알림(Toast Notification)으로 띄워주는 파이썬 스크립트/실행 프로그램입니다. 

## 기능 (Features)
- 컴퓨터학부 공지사항 게시판(학사공지 등)의 최신 게시글 넘버링을 확인합니다.
- 이전에 설정된 번호(`current_list_num.txt`)보다 높은 번호의 새 공지가 올라오면 윈도우 우측 하단에 토스트 알림을 띄웁니다.
- 알림을 클릭하면 해당 공지글 페이지로 바로 이동합니다.
- 알림 표시에는 경북대학교 엠블럼(`knu-emblem.ico`)이 아이콘으로 사용됩니다.

## 요구 사항 (Prerequisites)
소스 코드를 직접 실행하는 경우 다음 패키지들이 필요합니다.
- Python 3.x
- `requests`
- `beautifulsoup4`
- `win11toast`

```bash
pip install -r requirements.txt
```

*(미리 컴파일된 `.exe` 파일을 사용하는 경우 위 과정은 생략 가능합니다.)*

## 파일 설명
- `main.py`: 메인 데몬 스크립트. 공지 크롤링 및 알림 트리거 역할을 합니다.
- `current_list_num.txt`: 마지막으로 확인한 공지사항의 번호가 저장되는 텍스트 파일입니다. 처음 실행 시 없으면 자동으로 0으로 간주하여 새로 생성됩니다.
- `knu-emblem.ico`: 윈도우 알림에 표시될 아이콘 파일입니다.
- `main.spec` / `dist/`: PyInstaller 등을 통해 실행 파일로 빌드하기 위한 설정 및 결과물 폴더입니다.

## 💻 윈도우 작업 스케줄러 등록 방법 (자동 실행 설정)

이 프로그램이 주기적으로 백그라운드에서 실행되며 새로운 공지를 바로바로 알려주도록 하려면 **Windows 작업 스케줄러(Task Scheduler)** 에 등록해야 합니다. 아래의 순서를 따라 등록해 주세요.

### 1. 작업 스케줄러 실행
- `Win + S` 키를 누르거나 시작 메뉴를 열고 **"작업 스케줄러"**를 검색하여 실행합니다.

### 2. 새 작업 만들기
- 우측 패널의 메뉴에서 **[작업 만들기...]**(기본 작업 만들기 아님)를 클릭합니다.

### 3. [일반] 탭 설정
- **이름**: `KNU 공지사항 알리미` (원하는 이름으로 자유롭게 설정)
- **설명**: `주기적으로 경북대 컴퓨터학부 공지사항을 확인하여 알림을 보냅니다.`
- 하단의 **[가장 높은 수준의 권한으로 실행(I)]** 항목에 체크합니다.
- (선택) 콘솔 창이 깜빡이는 것을 방지하려면 **[숨김(H)]** 속성에 체크합니다. (또는 PyInstaller 빌드 시 `--noconsole` 옵션 사용)

### 4. [트리거] 탭 설정 (실행 주기 설정)
- 하단의 **[새로 만들기...]** 버튼을 클릭합니다.
- **작업 시작**: 드롭다운에서 `로그온할 때` 또는 `예약 상태`를 선택합니다.
- **고급 설정**:
  - **[작업 반복 간격]**에 체크하고, 드롭다운에 원하는 주기(예: **`1시간`**, **`30분`** 등)를 직접 입력하거나 선택합니다.
  - 우측의 **[기간]**은 `무기한`으로 설정합니다.
- 설정을 마친 후 **[확인]**을 클릭합니다.

### 5. [동작] 탭 설정 (프로그램 실행 경로 설정 - ⭐중요)
- 하단의 **[새로 만들기...]** 버튼을 클릭합니다.
- **동작**: `프로그램 시작`
- **프로그램/스크립트**: **[찾아보기...]**를 클릭하여 빌드된 **`main.exe`** 파일의 경로를 선택합니다.
  *(소스코드로 실행할 경우 `python.exe` 혹은 `pythonw.exe` 경로를 선택하고, '인수 추가'란에 `main.py`를 적습니다.)*
- **[시작 위치(옵션)]**: `main.exe` (또는 `main.py`)가 위치한 **현재 폴더의 전체 경로**를 따옴표 없이 입력합니다. 
  - 📌 **예시:** `C:\Users\ChoiYoonho\Desktop\프로젝트\KNU_ToastNotification`
  - *(주의: 시작 위치를 입력하지 않으면 프로그램이 `current_list_num.txt` 및 아이콘 파일을 엉뚱한 곳에서 찾게 되어 오류가 발생할 수 있습니다.)*
- 마친 후 **[확인]**을 클릭합니다.

### 6. [조건] 및 [설정] 탭 (선택 사항)
- **조건 탭**: 노트북 사용자의 경우, `"AC 전원이 켜져 있는 경우에만 작업 시작"` 옵션을 **해제**해야 배터리 사용 시에도 알림이 울립니다.
- **설정 탭**: `"작업이 실패하는 경우 다시 시작(R)"`에 체크해 두면 프로그램 안정성에 도움이 됩니다.

### 7. 저장 및 테스트
- 모든 설정을 마치고 **[확인]**을 눌러 스케줄러 등록을 완료합니다.
- 팝업창에서 관리자 비밀번호를 요구할 경우 입력합니다.
- 작업 스케줄러 중앙 목록에서 방금 등록한 작업을 찾아 우클릭한 후 **[실행]**을 눌러 토스트 알림이 정상적으로 뜨는지(혹은 백그라운드에서 잘 켜지는지) 테스트해 보세요!
